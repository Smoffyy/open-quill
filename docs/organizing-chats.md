# Organizing Your Chats

## The sidebar list

Chats appear under **Recents**, newest first. **Star** a chat from its menu to move it into **Starred** at the top. The **Group by** button on Recents groups the list by date, by project, or not at all.

Each chat's menu (the **⋯** on hover, or the title in the top bar) has **Star**, **Add to project** or **Remove from project**, **Export as Markdown**, **Export as JSON**, **Rename** and **Delete chat**. A chat that is still writing a reply can be stopped from the same menu.

## All chats

**All chats** at the bottom of the sidebar list opens a full overview with **Active** and **Archived** tabs. Press **Select** to pick several chats, or **Select all**, and then **Archive**, **Unarchive** or **Delete** them in one go. Archived chats leave the sidebar but are kept until you delete them.

## Search

`Ctrl+Shift+F`, or the search button at the top of the sidebar, searches the titles and text of every chat you have. Type at least two characters; matches are highlighted and you can move through them with the arrow keys.

## Projects

A project groups chats around shared context. Open **Projects** in the sidebar to see them all, search them, sort them, or **New project**.

Inside a project you get:

- **Instructions** that apply to every chat in the project.
- **Files**: one shared workspace for the whole project. Upload files or whole folders, drag them in, create new files and edit them in place. Every chat in the project can read, edit and run what is there, and a bar shows how much of the project's storage is used. **Download all** saves it as a zip.
- A composer for starting a new chat inside the project, and the list of chats already in it.

Move an existing chat in or out with **Add to project** in its menu or the composer's **+** menu. Deleting a project deletes its files but keeps its chats.

## Artifacts

**Artifacts** in the sidebar lists every file the assistant has created across all your chats, with a filter by file type. Click one to open the chat it came from. See [Artifacts & Sandbox](artifacts-sandbox.md).

## Scheduled tasks

**Scheduled** in the sidebar (or the small button next to **New**) lists tasks that run a prompt for you on a schedule: every day, on weekdays, on a weekday each week, every few minutes or hours, or once. Start one from the cards at the bottom of the page, such as **Daily briefing** or **Weekly review**.

Each run creates a new chat with the result. On each task you can **Run now** to open a fresh run straight away, **Pause** or **Resume** it, or delete it. Sort the list by next run or by creation date.

## Export and import

**Settings → General → Export everything** downloads one JSON file with your chats, styles, memory and preferences. **Import** reads such a file back: its chats are added, your profile data is merged, and nothing you already have is overwritten.

To save a single chat, use **Export as Markdown** or **Export as JSON** in its menu.
