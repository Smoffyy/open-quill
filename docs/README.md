## Conventions

- **Bold** marks a label, button or field exactly as it appears in the app.
- Shortcuts are written in their Windows and Linux form. On macOS, `Ctrl` is `Cmd` and `Alt` is `Option`. Every shortcut can be rebound, see [Keyboard Shortcuts](keyboard-shortcuts.md).
- Anything under **Admin Panel** needs an editor, publisher or owner account. Everything else works for any signed-in member.
- Open Quill has two interface presets, Anthropic-style and OpenAI-style. These docs describe the Anthropic layout, which is the default. Where the OpenAI layout puts something in a different place, it is called out.
