Open Quill 28 (OQ 28) is the next major release of Open Quill, building on OQ 27 with a strong focus on coding, long conversations, and cloud model support. This release introduces Code, a dedicated workspace where the assistant builds, runs, and debugs projects with a live files panel and Plan mode, along with rolling summaries and exact token counts that keep long chats on track, cloud models that configure themselves, and new chat features such as PDF export, tags, and Mermaid diagrams, making Open Quill more capable, more reliable, and more polished than ever.

As with any major release, you may encounter occasional bugs as we continue refining the platform through future updates.

For a complete list of changes, see the `Changelog` menu.
